# DS2 Photo Frame

An unofficial fan-made photo composition tool inspired by the photo mode visual style of *DEATH STRANDING 2: ON THE BEACH*.

Open the site here:

https://mnstr5hotel.github.io/ds2-photo-frame/

## About

DS2 Photo Frame lets you upload a local image, apply game-style frames and stickers, adjust the composition, recolor stickers, and export the final result as a PNG image.

The tool is designed as a simple browser-based editor. Your selected photo is processed locally in the browser and is not uploaded by this project.

## Features

- 41 photo frames based on the current asset handoff
- 24 selectable stickers
- 24 sticker color options
- Photo positioning, scaling, rotation, centering, and edge snapping
- Sticker positioning, scaling, rotation, color changes, and layer switching
- Undo and redo support
- PNG export at 2560 x 1440
- Chinese and English interface labels

## Notes

This project is a static website hosted with GitHub Pages. Public hosting means the website files and included visual assets can be accessed by visitors.
